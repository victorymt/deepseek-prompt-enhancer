# DeepSeek Prompt Enhancer（DSPM）

给 [DeepSeek](https://chat.deepseek.com) 网页版加两样东西：一个提示词模板库（`{{变量}}` 留空位，填完再发），和一个任务面板（贴一段文字，点一下，翻译 / 提示词增强 / 润色直接出结果）。

纯本地运行，**不发送任何网络请求**，提示词只存在你自己浏览器的 localStorage 里。

![版本](https://img.shields.io/badge/version-0.3.0-blue)
![许可](https://img.shields.io/badge/license-MIT-green)

## 特性

- **一键插入** —— 点「提示词」按钮选模板，或 `Alt+P` 打开面板
- **变量空位** —— `{{主题}}` 这样的占位符，插入后自动选中，直接打字覆盖
- **默认值** —— `{{字数=300}}` 预填 300，可改
- **下拉选择** —— `{{语气:正式,轻松,毒舌}}` 渲染成下拉框
- **多行输入** —— `{{原文@long}}` 渲染成文本域
- **选填项** —— `{{备注?}}` 留空则保留占位，不删文字
- **桌面 Tab 跳格** —— 插入后按 `Tab` 在空位间跳转，跳完自动交还焦点
- **移动端表单** —— 手机上弹底部抽屉，逐项填写，填完自动收起
- **面板可调** —— 拖拽顶部手柄调高度，双击恢复默认，高度会记住
- **原生撤销** —— 插入走 `execCommand`，`Ctrl+Z` 能整段撤销

### 任务面板（0.3.0 新增）

- **四个内置用途** —— 提示词增强、翻译、润色、提问，开箱即用，不用配置
- **一次点击出结果** —— 贴文字 → 点「运行」→ 自动新建对话、组指令、发送、等写完、取回结果
- **每次新开对话** —— 不复用上下文，翻译任务不会看到上一次提问的内容
- **结果卡片** —— 按时间倒序留在面板里，可复制、可回原对话查看、可重跑
- **刷新可续** —— 跑到一半刷新页面，会自动接上等结果
- **零 API** —— 不填 key、不改设置，全靠操作页面本身

## 使用

### 打开面板

| 方式 | 说明 |
|---|---|
| 点「提示词」按钮 | 输入框工具条里的第三个胶囊 |
| `Alt+P` | 全局快捷键，开/关面板 |
| `Alt+T` | 直接打开「任务」页签 |
| 输入框为空时敲 `/` | 直接唤起并开始搜索 |

### 移动与调整面板

面板顶部有两个手柄，各管一件事：

| 手柄 | 操作 | 效果 |
|---|---|---|
| 顶部中间的横条 | 拖动 | **移动面板位置**，位置会记住 |
| 右上角 `⤡` | 上下拖动 | 调整面板高度，高度会记住 |
| 横条 | 双击 | 位置和高度一起恢复默认 |

移动端只有横条，下拉超过一定距离会收起面板。

面板顶部有「模板 / 任务」两个页签。

### 跑任务（翻译 / 提示词增强 / 润色）

1. `Alt+T` 或点面板里的「任务」页签
2. 选一个用途（提示词增强 / 翻译 / 润色 / 提问）
3. 把要处理的文字贴进上面的框
4. 点「运行」（或 `Ctrl+Enter`）

然后脚本会自动走完：**新开对话 → 组指令 → 填入 → 发送 → 等它写完 → 取回结果**。结果出现在下面的卡片里，带「复制 / 打开对话 / 重跑 / 删除」。

运行中按钮会变成「停止」，点了会保留已经生成的那部分。

> 每次任务都会新开一条对话，不复用上下文。所以侧栏会多出记录，这是隔离的代价。

### 写模板

在面板里点「＋ 新建」，正文里用 `{{}}` 标记空位：

```
请把下面这段内容改写成 {{字数=300}} 字以内的摘要，
语气保持{{语气:正式,轻松,简洁}}。

原文：
{{原文@long}}
```

编辑器下方会实时显示检测结果，例如：

> 检测到 3 个空位：**字数**`默认`、**语气**`选 3 项`、**原文**`多行`

### 变量语法

| 写法 | 含义 | 表单控件 |
|---|---|---|
| `{{名字}}` | 普通空位 | 单行输入 |
| `{{名字=默认值}}` | 带默认值 | 单行输入（预填） |
| `{{名字:甲,乙,丙}}` | 下拉选择 | 下拉框 |
| `{{名字:甲,乙=乙}}` | 下拉 + 默认选中 | 下拉框（预选乙） |
| `{{名字@long}}` | 多行 | 文本域 |
| `{{名字?}}` | 选填 | 输入框，留空保留占位 |
| `{{名字=默认@long}}` | 组合 | 多行 + 预填 |

修饰符可组合，顺序不限：`{{风格:甲,乙@long}}`、`{{备注?@long}}` 都可以。

也兼容单花括号 `{名字}`，但只认纯名字——`{{ }}` 才是推荐写法，因为单括号会和 JSON、LaTeX 的 `\frac{a}{b}` 撞车。

### 桌面端：Tab 跳格

插入后第一个空位会高亮选中：

1. 直接打字覆盖
2. 按 `Tab` 跳到下一个
3. `Shift+Tab` 回上一个
4. 跳完一圈后 `Tab` 恢复正常焦点行为
5. `Esc` 提前结束

没填的空位**不会**被删除，会原样留在文本里。

### 移动端：表单填写

手机上点模板后会插入文本并弹出底部抽屉，每个空位一个输入框：

- 下拉项直接点选
- 默认值已预填，可以直接改
- 选填项留空则保留 `{{原名}}` 占位
- 点「填入」一次性替换全部，抽屉自动收起

抽屉顶部有拖拽手柄，往下拉可以收起。

### 桌面端：调整面板

面板顶部有拖拽手柄：

- 往下拖 → 缩小面板
- 往上拖 → 放大面板
- 缩到最小继续拽 → 关闭
- 双击手柄 → 恢复默认高度
- 高度会被记住，下次打开沿用

## 数据存储

所有数据存在浏览器的 `localStorage`，键名 `dspm.v1`：

```json
{
  "schemaVersion": 1,
  "prompts": [
    {
      "id": "p_xxx",
      "title": "论文摘要润色",
      "body": "请把 {{原文}} 改写成 {{字数=300}} 字摘要",
      "usageCount": 12,
      "lastUsedAt": 1730000000000
    }
  ],
  "settings": { "braceStyle": "both", "panelMax": 0 }
}
```

- 列表按最近使用时间倒序
- 搜索同时匹配标题和正文
- 没有任何联网上报，换浏览器/清缓存会丢失数据（导入导出在做）

任务结果存在另一个键 `dspm.tasks.v1`，和提示词分开，互不影响：

```json
{
  "schemaVersion": 1,
  "items": [
    {
      "id": "t_xxx",
      "preset": "translate",
      "presetName": "翻译",
      "input": "原文（超过 4000 字符只存前 4000）",
      "output": "译文",
      "status": "done",
      "mark": "⟦a1b2⟧",
      "href": "https://chat.deepseek.com/a/chat/s/...",
      "createdAt": 1730000000000,
      "finishedAt": 1730000012000
    }
  ]
}
```

- 每个用途最多保留最近 **20 条**，单条结果超过 **20000 字符**会截断
- 存储写满时会自动砍掉最旧的一半再试一次，不会让你辛苦跑出来的结果直接消失
- 运行中的现场存在 `sessionStorage`（`dspm.run.v1`），只用来刷新续跑，关标签页即失效

## 实现要点

### 输入框是受控 React 组件

直接 `textarea.value = x` 不会同步 React 状态，发送按钮拿不到内容。脚本优先用：

```js
document.execCommand('insertText', false, text)
```

它同时兼容 `textarea` 和 `contenteditable`，并且**保留浏览器原生撤销栈**。失败时才回落到「原生 setter + `InputEvent`」。

### 不用 hash 类名定位

DeepSeek 的类名形如 `_27c9245`，每次构建都会变。脚本只依赖：

```js
textarea[placeholder] → textarea → [contenteditable="true"]
```

三级回退，全挂时降级提示而不是报错。

### 按钮并入原生工具条

「提示词」按钮不是悬浮球，而是按 DeepThink / Search 的真实计算样式对齐的胶囊：高 34px、圆角 18px、内边距 10px、字号 13px/500，间距 10px。窄屏下自动缩成纯图标，避让右侧的发送按钮。

### UI 在 Shadow DOM 内

所有面板样式都封装在 Shadow DOM 里，不受 DeepSeek 的 `.ds-*` 全局样式影响，也不会污染页面。

### 任务怎么跑：串行，一次一个

不做队列、不做并发、不做时间片。一次任务走完四步：

1. **新开对话** —— 找「开启新对话」按钮（只认文本，不认哈希类名）
2. **组信封** —— `角色指令 + 边界声明 + 唯一标记 + 原文`，填进输入框
3. **发送** —— 派发原生 `Enter` 键，路径和人类一致；没清空输入框就改点发送键
4. **等写完** —— 三重信号取交集：「停止生成」消失 **且** 文字连续 1.6 秒不变

`DeepThink` 的思考阶段会让「停止生成」持续很久，这算正常，不会被误判成写完。

### 公式为什么不能直接 innerText

DeepSeek 用 KaTeX 渲染公式，DOM 里每个字符、每个上下标都是独立节点。直接取 `innerText` 会得到：

```
一个普通 Poisson 过程
𝑁
(
𝑡
)
N(t)，表示到时刻
𝑡
t 为止发生的"事件次数"
```

一条带公式的回答能膨胀到 983 行。所以 `IO.toMarkdown()` 改成按块递归遍历，
遇到 `.katex` 就取出它自带的 `<annotation encoding="application/x-tex">` 里的
**原始 LaTeX 源码**，还原成 `$N(t)$`（行内）或 `$$...$$`（独立公式）。

实测同一段回答：983 行 → 143 行，公式全部正确还原。

顺带也处理了标题、列表、粗体、代码块、表格，让结果卡片能直接复制成可用的 Markdown。

### 指令为什么这么短

内置指令控制在 60 字左右，只保留角色 + 硬约束。长前言会挤占注意力、抬高成本，还可能被忽略；明确的祈使句和禁止项更管用。

### 原文为什么要包在 `<<< >>>` 里

每次新开对话，理论上已经干净了。但仍会声明边界，因为：

- 模型偶尔会「聪明」地去联系上下文
- 万一某次新建对话没成功，边界是最后一道保险

### 标记为什么用可见字符

`⟦a1b2⟧` 而不是零宽字符：零宽字符复制粘贴容易丢，而且和脚本原有的 `ZWSP` 转义机制冲突。取回结果时会把标记剥掉。

## 已知限制

- DeepSeek 前端改版可能导致失效，定位逻辑集中在 `IO` 层，通常只需改这一层
- 数据只在本机，不同步、不备份（导入导出在计划中）
- **任务面板会自动发送**：模板功能仍是「填好等你自己按回车」，任务面板是「点运行就发出去」
- **每次任务新开对话**：侧栏会多出记录，目前不自动清理（怕误删，宁可留给你自己删）
- **同一时刻只跑一个**：不做并发。想同时跑多个，开多个标签页
- **依赖页面结构**：新建对话按钮、停止生成按钮、回答容器都是启发式定位，改版可能失效；失效时任务会明确报错，不会静默卡住
- **频率限制**：短时间连续跑多个任务，可能被服务端限流；脚本有 5 分钟单任务超时和失败退避，但不做无人值守批量提交
- 提示词不支持分组标签（在计划中）

## 开发

单文件，无构建、无依赖。改完直接覆盖 `dspm.user.js` 即可。

```
dspm.user.js
├── IO       唯一接触 DeepSeek DOM 的层（选择器、插入、定位、发送、取答复）
├── Parser   {{变量}} 扫描 / AST / 插入文本生成
├── Session  Tab 跳格会话
├── Store    localStorage 持久化（提示词）
├── PRESETS  四个内置任务用途
├── Tasks    任务结果持久化 + 上限裁剪
├── Runner   任务状态机：新建 → 填入 → 发送 → 等写完 → 取回
└── UI       Shadow DOM 面板 / 表单 / 拖拽 / 任务页签
```

调试时脚本会在 `window.__DSPM__` 暴露内部对象：

```js
__DSPM__.parse('{{a=1}}', true)   // 看解析结果
__DSPM__.Store.data               // 看提示词存储
__DSPM__.Tasks.data               // 看任务结果
__DSPM__.destroy()                // 卸载

__DSPM__.probe()                  // 自检：关键选择器还能不能命中
__DSPM__.run('translate', 'hello')// 直接跑一个任务
```

`probe()` 是最快的排障入口 —— DeepSeek 改版后先跑它，看哪一项是 `false`：

```js
{
  href: 'https://chat.deepseek.com/...',
  composer: true,      // 输入框找得到吗
  newChat: true,       // 「开启新对话」按钮找得到吗
  generating: false,   // 当前是否在生成
  answers: 3,          // 页面上抓到几个回答容器
  lastAnswerLen: 812   // 最后一条回答的长度
}
```

语法检查：

```bash
node --check dspm.user.js
```
